<Note>
Warden loads local Lua packages from the `wardenrotations` folder in your WGG directory.
</Note>

## Quick start

1. Open your WGG directory. A standard installation uses `C:/WGG`.
2. Create `wardenrotations` if it does not exist.
3. Copy a package into that folder and add its Lua files to `loadorder.json`.
4. Start WGG and select the routine from the Active Routine menu.

Your folder should look like this:

```text
C:/WGG/
  wardenrotations/
    loadorder.json
    warrior/arms/basic/
      spells.lua
      gui.lua
      rotation.lua
```

Read [local packages](/get-started/local-packages) for the folder layout, then follow [your first routine](/get-started/first-routine) to build a working package.

For enemy targeting, arena units, crowd control, and burst handling, see [PvP rotation basics](/pvp).

## How a package works

Each Lua file receives the `warden` framework API and the `WGG` host API. A typical package:

- defines its spellbook in `spells.lua`;
- creates settings in `gui.lua`; and
- registers the routine in `rotation.lua`.

The [reference](/reference/routines) documents the APIs available to rotation authors.
