<Note>
These guides show you how to create a rotation package and load it from your local WGG directory.
</Note>

## Start here

1. Create a `wardenrotations` folder in your WGG directory.
2. Add a rotation package and list its files in `loadorder.json`.
3. Start WGG and select your routine.

The [local packages](/get-started/local-packages) guide explains the folder layout. Then follow [your first routine](/get-started/first-routine) to build a small working package.

For enemy targeting, arena units, crowd control, and burst handling, see [PvP rotation basics](/pvp).

## What you can build

- Selectable routines.
- Spell objects, callbacks, and execution helpers.
- Unit, aura, list, configuration, UI, alert, and status-frame helpers.

Each loaded file receives the `warden` framework API and the `WGG` host API when it needs host functionality. The [reference](/reference/routines) documents the APIs available to rotation authors.
