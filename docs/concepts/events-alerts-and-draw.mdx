## Warden Insight

Warden Insight is the framework-owned tactical feed. It shows the active
routine's selected action, reactive utility, planned cooldowns, and nearby
enemy count.

- Click **X** in its header to hide it. Re-enable it under **Settings > Modules
  > Insight**.
- Click **D** to dock it below the Warden StatusFrame. It will then move with
  the StatusFrame.
- Click **-** to collapse it to its header; click **+** to expand it again.
- The footer shows the current nearby hostile count without exposing a
  configurable range. The count uses Warden's nearby-hostile snapshot and is
  available out of combat as well as in combat.

If Insight itself disappears outside combat, turn off **Show only in combat**
in **Settings > Modules > Insight**.

### Rotation integration

Insight does not infer every panel from a spell callback:

- **Now** is automatic. A successful `spell:execute()` that submits a cast
  request is observed by the framework and shown as the selected action.
- **Plan** is explicit. A rotation registers its cooldown rows with
  `warden.Insight:RegisterProfile(namespace, { cooldowns = { ... } })`.
  Without that profile, Insight correctly displays **No cooldown profile**.
- **React** is explicit. When a rotation finds a meaningful interrupt, dispel,
  soothe, taunt, or other reactive target, it publishes a short-lived entry
  with `warden.Insight:Publish(channel, payload)`. Do not publish a placeholder
  when no valid target exists.

```lua
warden.Insight:RegisterProfile("MyRoutine", {
  cooldowns = {
    { spell = spells.major_cooldown, enabled = function() return cooldownsOn end },
  },
})

warden.Insight:Publish("interrupt", {
  spell = spells.kick,
  target = interruptTarget,
  reason = "Dangerous cast",
  ttl = 1.25,
})
```

Use alerts for visible, short-lived player feedback:

```lua
warden.alert("Interrupt ready", 6552)
```

## Frontal-cone preview

Enable **Settings > Modules > Draws > Draw 10 yd frontal cone** to show the
same player-facing 10-yard, 90-degree geometry used by
`player.enemiesincone(10, 90)`. It is a visual aid only; rotations must use
the cone query itself and continue to work when all drawing is disabled.

Drawing APIs are optional presentation helpers; every rotation must continue functioning when drawing is disabled. Avoid per-tick chat output—surface actionable failures through the framework error path instead.
