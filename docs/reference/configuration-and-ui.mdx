## `warden.Config`

```lua
warden.Config:Read(key, default)
warden.Config:Write(key, value)
warden.Config:SetDefault(key, value)
warden.Config:GetAll()
warden.Config:ClearCache()
```

Use `SetDefault` while defining a control and `Read` during routine execution. Keys are package-owned strings; prefix them with your namespace.

`warden.Config:Write(key, value)` returns `success, errorMessage`. Existing
packages may continue ignoring the result. Check it when a failed save should
be visible to the user; Warden validates serialization and leaves the previous
cached value untouched when persistence fails.

```lua
local saved, errorMessage = warden.Config:Write("myRoutine.useCooldowns", true)
if not saved then
  warden:Logger("Could not save setting: " .. tostring(errorMessage), "error")
end
```

## `warden.GuiBuilder`

```lua
local gui = warden.GuiBuilder:New()
local category = gui:Category("Package name", 100)
local tab = category:Tab("General")
tab:Checkbox({ text = "Enable", key = "package.enabled", default = true })
```

Supported stable elements are `Button`, `Checkbox`, `EditBox`, `Header`, `Slider`, `DoubleSlider`, `Dropdown`, `ColorPicker`, `HalfLabel`, and `Spacer`. Each accepts one configuration table; see the [GUI guide](/build/gui-and-settings) for the recommended shape.

## `warden:AddGlobalToggle`

Creates a persistent framework toggle and returns its state handle. Prefer a
regular GUI control for package-specific numeric tuning.

```lua
local cooldowns = warden:AddGlobalToggle({
  label = "Cooldowns",
  var = "myPackage.cooldowns",
  icon = 318,
  value = true,
})

cooldowns:SetValue(false)
print(cooldowns:GetValue()) -- false
```

| Handle method | Behavior |
| --- | --- |
| `GetValue()` | Returns the current boolean state. |
| `SetValue(value)` | Normalizes and persists the boolean state, refreshes a framework tile when present, and returns the resulting state. It does not invoke `onClick`. |
| `UpdateDisplay()` | Repaints a framework-owned tile. It is a safe no-op when the package owns presentation. |
| `SetCustomText(text, color?)` | Changes the framework tile's tooltip text and optional tooltip color. |

The fully qualified public method names are `WardenGlobalToggle:GetValue`,
`WardenGlobalToggle:SetValue`, `WardenGlobalToggle:UpdateDisplay`, and
`WardenGlobalToggle:SetCustomText`.

Toggle values use the StatusFrame's own persistent storage. Writing the
toggle's `var` through `warden.Config` does not change its value.

Set `ownsPresentation = true` when a package draws its own control with
`CreateFrameLayout` and only needs Warden to own state, persistence, callbacks,
and status-hotkey integration. No shared StatusFrame tile is created. The first
registration of a `var` determines its presentation mode.

```lua
local customToggle = warden:AddGlobalToggle({
  label = "GSTV Cooldowns",
  var = "gstv.cooldowns",
  value = true,
  ownsPresentation = true,
})

-- In the package-owned button's click handler:
customToggle:SetValue(not customToggle:GetValue())
```

## StatusFrame theme

`warden:SetStatusFrameTheme(palette)` changes the shared StatusFrame for the
current session. All five RGBA roles are required and every component must be
between `0` and `1`. The call returns `success, errorMessage`; invalid palettes
do not partially apply.

```lua
local applied, errorMessage = warden:SetStatusFrameTheme({
  background = { 0.03, 0.05, 0.09, 1.00 },
  border = { 0.20, 0.35, 0.46, 0.92 },
  disabled = { 0.50, 0.59, 0.66, 0.76 },
  enabled = { 0.29, 0.60, 0.92, 1.00 },
  hover = { 0.05, 0.12, 0.18, 1.00 },
})
```

The theme applies immediately to existing controls and to controls registered
later. Theme ownership is global and last-call-wins. It is not persisted;
`warden:ResetStatusFrameTheme()` restores the framework defaults.

## Framework version

```lua
local version = warden:GetVersion() -- "2.1.0"
local info = warden:GetVersionInfo()
-- info.version, info.apiVersion, info.revision
```

`apiVersion` is the compatibility level packages should use for feature gates.
`revision` is an optional opaque fingerprint of the ordered framework source
actually loaded. It may be absent while the launcher is still loading; compare
it for diagnostics but do not parse it.

<Note>
Only APIs and returned fields documented here are public. Raw implementation
fields such as `button`, `border`, `GlobalStatusFrame`, `StatusFrame`,
`configFrame`, and their child regions may change without compatibility
guarantees. Use `CreateFrameLayout` for package-owned frames and the supported
theme methods for the shared StatusFrame.
</Note>

## `warden:CreateFrameLayout`

Creates a small, persistent layout controller for a package-owned frame. It is
for runtime widgets such as a compact alert, timer, or icon group; use
`GuiBuilder` for configuration pages and `AddGlobalToggle` for shared rotation
controls.

```lua
local layout, errorMessage = warden:CreateFrameLayout({
  key = "sampleFeral.alert",
  name = "SampleFeralAlertFrame",
  width = 180,
  height = 40,
  defaultPoint = { "CENTER", "UIParent", "CENTER", 0, 160 },
  defaultScale = 1,
  minScale = 0.75,
  maxScale = 1.5,
})

if not layout then
  error(errorMessage)
end

local icon = CreateFrame("Frame", nil, layout.frame)
icon:SetSize(32, 32)
layout:Anchor(icon, "LEFT", layout.frame, "LEFT", 8, 0)
```

`key` is required and must be stable and package-owned. Position, scale, and
lock state are saved in the active Warden profile under that key. The helper
creates a plain `Frame` when `frame` is omitted; alternatively, pass an
existing frame in `frame = myFrame`.

| Method | Purpose |
| --- | --- |
| `FrameLayout:SavePosition()` | Store the frame's current anchor. |
| `FrameLayout:SetPosition(point, relativeTo, relativePoint, x, y)` | Move and persist the whole package frame. `relativeTo` can be a frame or its global name. |
| `FrameLayout:RestorePosition()` / `FrameLayout:ResetPosition()` | Apply the saved anchor or restore `defaultPoint`. |
| `FrameLayout:SetScale(value)` / `FrameLayout:GetScale()` | Persistently set or read scale, clamped by `minScale` and `maxScale`. |
| `FrameLayout:SetLocked(value)` / `FrameLayout:IsLocked()` | Enable or prevent dragging. |
| `FrameLayout:Anchor(widget, point, relativeTo, relativePoint, x, y)` | Clear and apply a simple anchor to one child widget. |
| `FrameLayout:EnableDragging(handle?)` | Add left-button drag support to `handle` or the package frame. |

`onMoved`, `onScaleChanged`, and `onLockChanged` can be supplied in the
options table when a package needs to react to a layout change. Individual
widgets are positioned by their anchors; the framework does not auto-layout or
reposition them after that.

<Note>
Do not use this helper to move Blizzard protected frames or action-bar widgets.
It is intended for frames created and owned by the rotation package.
</Note>
