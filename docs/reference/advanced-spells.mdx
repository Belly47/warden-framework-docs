---
title: "Advanced spell helpers"
description: "Timing, cast requests, charges, and ground-target helpers."
---

The regular [spell reference](/reference/spells) covers the common path. These helpers are useful when a package needs to account for latency, spell queues, channels, or ground-targeted abilities.

## Timing and cast state

```lua
local gcd = spell:currentgcd()
local queueWindow = spell:queuewindow()
local latencyMs = warden.Network.GetLatency()
local castTime = spell:getcasttime()
local channelTime = spell:getchanneltime()
```

`warden.Network.GetLatency()` returns world latency in milliseconds and falls
back to home latency when world latency is unavailable. `spell:latency()` is a
deprecated compatibility alias.

To inspect the player's current cast or channel:

```lua
local cast = warden.SpellHandler.GetCurrentCastInfo()
if cast and cast.interruptible then
  -- cast.kind is "cast" or "channel".
  -- cast.spellID, cast.remains, and cast.percent are also available.
end
```

`spellID` is the active spell ID and `remains` is measured in seconds. For a
normal cast, `percent` rises from 0 to 100. For a channel, it preserves the
framework's remaining-progress convention and falls from 100 to 0. The record
is captured from one secret-safe player cast snapshot, so its fields describe
the same API sample.

`warden.StopCasting()` returns a success value and a reason:

```lua
local stopped, reason = warden.StopCasting()
```

## Charges and talents

```lua
local charges = spell:charges()
local maximum = spell:maxcharges()
local fractional = spell:chargesfractional()
local nextCharge = spell:timetonextcharge()
local allCharges = spell:timetofull()
local talentRank = spell:rank()
```

`warden.SpellHandler.GetPointsInTalent(name)` is available when the package needs to look up a talent by name.

## Cast requests

`spell:cast(unit)` keeps its Boolean result for normal rotation code. The most recent structured request can be inspected when debugging or building a queue:

```lua
local request = spell:lastcastrequest()
if request then
  -- request.requestID, request.status, and request.reason
end
```

Requests can also be retrieved with:

```lua
local request = warden.SpellHandler:GetCastRequest(requestID)
```

Statuses include `submitted`, `success`, `failed`, `interrupted`, and `rejected`.

Object-backed units are resolved to a verified native token before submission.
If an object cannot be addressed safely, `spell:cast(unit)` returns `false`,
records no request, and does not change the player's selected target.

## Ground-targeted spells

To place a spell directly at the current target, use `castgroundat`. It resolves the target's WGG world position and places the ground cursor through `WGG.MouseClick`:

```lua
if spells.Meteor:castgroundat("target") then
  return true
end
```

`castgroundat(unit)` and `castandclickraw(x, y, z)` both start the spell and
place its ground cursor. When another system has already opened the placement
cursor, use the placement-only forms instead:

```lua
spell:placegroundat(mouseoverUnit)
spell:placegroundraw(x, y, z)
```

These placement-only helpers never cast the spell a second time. They return
`false` when no ground cursor is active or when WGG rejects the world click.

For clustered placement, `smartaoeposition` finds the best position using the active enemies and group units. `smartaoe` casts at that position:

```lua
local position = spells.GroundEffect:smartaoeposition(target, {
  filter = function(unit)
    return unit.enemy and unit.alive
  end
})

if position then
  spells.GroundEffect:smartaoe(target, {
    filter = function(unit)
      return unit.enemy and unit.alive
    end
  })
end
```

Use `ignoreEnemies` or `ignoreFriends` when the spell should only consider one side, and `minHits` to require a cluster size. A position result contains `x`, `y`, `z`, and `hitCount`.

Ground-targeting entry points return `false` or `nil` instead of propagating an
internal provider error. To confirm the loaded implementation and inspect the
last protected error for a spell:

```lua
local status = warden.SpellHandler:GetGroundTargetingStatus(spells.Meteor)
print(status.revision, status.phase, status.targetingActive, status.pendingCode,
  status.clickAttempted, status.clickAccepted,
  status.lastError or status.lastFailure or "no ground-target failure")
```
