`warden.Enums` and `warden.Lists` provide framework-maintained reference data. Treat enum tables as read-only. The exact available categories are versioned with the framework and should be feature-checked before use.

## Time to die

TTD is an estimate in **seconds**, learned from observed health loss rather
than a fixed NPC value. While in combat, Warden samples active enemies within
40 yards about every 0.20 seconds, recording a point when health changes by at
least 0.5%. It retains up to 10 seconds and 100 samples per unit. After three
samples, the estimate is the observed time per health-percent lost, multiplied
by current health percent.

`warden.groupttd()` averages only valid estimates under 6000 seconds. It
returns `0` until at least one nearby active enemy has enough history. A dummy
returns `999`; `GetTTD(unit)` returns `8888` when the unit has no TTD record
and `7777` while it has insufficient samples. Treat those values as unknown,
not literal durations.

```lua
local ttd = warden.TTD.GetTTD(target)
if ttd < 15 then
  -- The target is estimated to die within 15 seconds.
end

local maxTTD, averageTTD, enemies = warden.TTD.GroupTTD()
```

TTD depends on `warden.activeenemies`; it cannot estimate units that have not
been discovered or that are outside the 40-yard sampling range.

## Incoming damage and defensive coverage

`warden.Lists.DefensiveInfo[spellID]` includes both a defensive `category`
and a `coverage` profile: `all`, `physical`, `magic`, or `none`.
`unit.defensivecoverage` exposes the profile of a recognized active defensive.

`warden.GetDamageType(spellID)` returns metadata with `type` (`physical`,
`magic`, `mixed`, or `unknown`), an optional magical `school`, and optional
`tankBuster` / `partyDamage` labels. Curated
`warden.Lists.EncounterDamage` entries win before
`warden.ObservedDamageTypes`, which learns spell schools from combat-log damage
to the player. Unknown spells stay `unknown`.

```lua
local incoming = warden.GetDamageType(388863)
if incoming.tankBuster and warden.DefensiveCovers(48707, incoming.type) then
  -- Anti-Magic Shell is a suitable broad magic counter.
end

if player.defensivecoverage == "physical" then
  -- A physical-only defense such as Blessing of Protection is currently up.
end
```

Coverage is deliberately broad, not a guarantee that a particular mechanic is
negated: encounter rules, AoE-only effects, absorbs, immunities, and
reflectable spells still need ability-specific handling. `DefensiveCovers`
returns `false` for unknown incoming damage so rotations never infer a
school-specific counter from a name or visual effect.

For compatibility, `player.aura(stanceSpellID)` also recognizes an active
stance/form when the client exposes it only through the stance bar. New code is
clearer when it calls `warden.IsStanceActive(spells.BattleStance)` directly.

The supported DR categories are exactly `incap`, `disorient`, and `stun`.
Results are bounded by Warden's maintained aura/DR lists; full damage immunity,
every soft-control effect, and arbitrary encounter immunity are outside this
stable PvP contract.
