---
title: "Helpers and enums"
description: "Stable Warden helpers for common rotation work."
---

| API | Use |
| --- | --- |
| `warden.alert(input, iconID, payload)` | Show an in-game alert. |
| `warden.texture(idOrPath, size)` | Produce formatted spell/texture text for UI labels. |
| `warden.gcd()` | Get the current global cooldown value. |
| `warden.groupttd()` | Get the average valid enemy time-to-die value. |
| `warden.grouphp(distance)` | Read group-health information within a range. |
| `warden.grouphpcount(distance, percent)` | Count group members at or above a health threshold. |
| `warden.random(min, max)` | Get a random integer in the given range. |
| `warden.blockmovement(timewindow)` | Temporarily block movement behavior. |
| `warden.IsShapeshiftSpellActive(spell)` | Check whether the player has the supplied form, aura, or stance spell active. |
| `warden.IsStanceActive(spell)` | Alias for `IsShapeshiftSpellActive`; use this name in Warrior stance logic. |
| `warden.CanApplyCc(unit, category, minMult)` | Check diminishing-return eligibility for `incap`, `disorient`, or `stun`. |

`warden.Enums` and `warden.Lists` provide framework-maintained reference data. Treat enum tables as read-only. The exact available categories are versioned with the framework and should be feature-checked before use.

For compatibility, `player.aura(stanceSpellID)` also recognizes an active
stance/form when the client exposes it only through the stance bar. New code is
clearer when it calls `warden.IsStanceActive(spells.BattleStance)` directly.
