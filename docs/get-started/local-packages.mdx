---
title: "Local packages and load order"
description: "Put a rotation package where Warden discovers it and control its execution order."
---

The launcher looks for local rotations in your WGG directory. Create a `wardenrotations` folder there; for a standard installation, that path is `C:/WGG/wardenrotations`.

If you downloaded a package as a ZIP file, extract it so that the package files sit inside `wardenrotations`. Do not leave an extra folder level between `wardenrotations` and `loadorder.json`.

Use this structure:

```text
wardenrotations/
  loadorder.json
  warrior/arms/basic/
    spells.lua
    gui.lua
    rotation.lua
```

The root manifest lists files without the `.lua` extension and preserves order:

```json
[
  "warrior/arms/basic/spells",
  "warrior/arms/basic/gui",
  "warrior/arms/basic/rotation"
]
```

Load spells before code that reads them, then build UI, then register the routine. A manifest entry that does not exist is a load error with its exact path.

## Sharing packages

For public downloads, publish the ZIP as a release asset on GitHub or another file host, then link to that release from the docs. Keep the ZIP separate from the documentation source so package versions can be released independently.
