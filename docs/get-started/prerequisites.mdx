---
title: "Prerequisites"
description: "What a rotation author needs before writing code."
---

You need Warden Framework v2, a Lua editor, and access to your WGG directory. Local packages are loaded from the `wardenrotations` folder inside that directory.

Each loaded Lua file receives:

```lua
local WGG, warden = ...
```

`warden` is the framework API. `WGG` is the host API; use it only where a documented Warden feature requires it. Do not depend on launcher globals.

<Warning>
Do not add framework files to your rotation package. A rotation package should contain only its manifest and its own Lua files.
</Warning>
