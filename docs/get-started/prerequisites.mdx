---
title: "Prerequisites"
description: "What a rotation author needs before writing code."
---

You need a Warden Framework v2 installation, a Lua editor, and a local rotation folder. The framework and local packages load through the Warden launcher; you do not need storage credentials or marketplace code to author a local package.

Each loaded Lua file receives:

```lua
local WGG, warden = ...
```

`warden` is the framework API. `WGG` is the host API; use it only where a documented Warden feature requires it. Do not depend on launcher globals or the legacy compatibility aliases.

<Warning>
Do not add framework files to your rotation package. A rotation package should contain only its manifest and its own Lua files.
</Warning>
